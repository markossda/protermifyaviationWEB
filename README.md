# Protermify Aviation Static Site

This project builds a fully static aviation glossary from `aviation.json`.

## Build

```bash
python3 build_site.py
```

The generated site is written to `dist/`.

## Output

- Static HTML pages only for content
- Single shared CSS file
- Locale home pages
- Locale about pages
- Aviation glossary hub pages
- Category pages
- Individual term pages
- `llms.txt`
- `llms-full.txt`
- `sitemap.xml`
- `robots.txt`
